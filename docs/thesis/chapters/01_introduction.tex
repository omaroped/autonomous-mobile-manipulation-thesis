\section{Background and Motivation}
Smart manufacturing and Industry 4.0 paradigms demand increasingly flexible production
systems capable of reconfiguring rapidly in response to changing order profiles. Whereas
traditional fixed-line automation uses large, stationary robots dedicated to a single
station, emerging on-demand manufacturing scenarios require material to be transported
between stations dynamically and manipulation tasks to be performed at locations that
are not fixed in advance~\cite{masannek2026eaiws}. Autonomous Mobile Robots (AMRs) have
become a practical solution for intra-factory transport; the logical next step is
combining the mobility of an AMR with the manipulation capability of a robot arm---a
class of system known as a \emph{mobile manipulator}.

Mobile manipulators introduce a coupling challenge: the navigation and manipulation
subsystems must not only function correctly in isolation but also cooperate when
operating simultaneously or in close succession. A base that vibrates while driving
disturbs an unbraced arm; an arm that extends forward into the navigation sensor's
field of view inflates the obstacle cost map; a grasp that is planned from a pose
estimated before the robot moved will fail once the robot has navigated. These
integration faults are rarely visible in unit tests of individual subsystems and emerge
only when the full pipeline is exercised end to end.

This thesis investigates how to build, debug, and validate such an integrated pipeline
on a compact, commercially available cobot platform---the Agilex LIMO Cobot---in the
context of the RoboCup Smart Manufacturing League's Embodied Autonomous Intelligence
workshop scenario~\cite{masannek2026eaiws,dissanayaka2025sml}. The platform combines a
differential-drive mobile base (LIMO PRO, 4\,kg payload, 1\,m/s) with a six-degree-
of-freedom arm (myCobot 280, 250\,g payload, 280\,mm nominal reach), an Orbbec DaBai
depth camera, an EAI T-mini Pro LiDAR, and an NVIDIA Jetson Orin Nano compute unit.
All development is conducted in Gazebo Classic simulation under ROS~2 Humble, with
the explicit goal of deploying the validated software stack onto the physical hardware
as a subsequent phase.

\section{Problem Statement}
Building a reliable autonomous pick-and-place pipeline on a compact mobile manipulator
requires solving several tightly coupled sub-problems whose interactions produce
emergent failure modes not anticipated from individual component analyses. The core
challenges addressed in this work are:

\begin{itemize}
    \item \textbf{Environment mapping and localisation} in a constrained workspace,
    where the robot's own sensors can contaminate the map if not correctly configured.

    \item \textbf{Autonomous navigation} in the presence of a mounted arm whose
    geometry intersects the costmap's obstacle detection range, causing the robot to
    treat its own body as an impassable obstacle.

    \item \textbf{Object perception} using a depth camera whose physical minimum range
    is larger than the arm's grasp distance, creating a near-field blind spot that must
    be explicitly accounted for in the workflow.

    \item \textbf{Arm kinematics and reachability}, where the arm's short effective
    top-down reach and the base's forward geometry define a narrow feasible grasp zone
    that governs where the robot must stop relative to the target.

    \item \textbf{System integration}: sequencing navigation, visual docking, and
    manipulation in a single pipeline, including handling the inertial effects of the
    arm during base motion and ensuring that all pose references remain valid after the
    robot has moved.
\end{itemize}

\section{Research Objectives}
The primary objectives of this thesis are:

\begin{enumerate}
    \item Design and implement an autonomous navigation pipeline for the LIMO PRO
    platform in a simulated factory environment, including SLAM-based mapping and
    AMCL localisation.
    \item Integrate a perception system capable of localising a target object in the
    robot's manipulation workspace using an RGB-D depth camera.
    \item Execute a complete pick-and-place cycle that combines autonomous navigation
    with arm manipulation in a single coordinated pipeline.
    \item Establish a quantitative sim-to-real baseline by characterising the
    performance of the simulation pipeline as an upper bound before deploying on
    physical hardware.
\end{enumerate}

\section{Thesis Outline}
Chapter~2 presents a review of the relevant literature covering mobile robotics in
manufacturing, robotic grasping strategies, and integrated mobile manipulation systems.
Chapter~3 describes the methodology: the drive-mode selection rationale, the mapping
and localisation approach, the Nav2 navigation framework configuration, and the arm
kinematics and motion planning strategy. Chapter~4 details the system architecture and
implementation, including the hardware platform, software architecture, simulation
environment, perception subsystem, MoveIt~2 integration, and the significant
engineering faults encountered and resolved during development. Chapter~5 presents the
experimental results: the map quality evaluation, navigation performance, arm
reachability characterisation, grasp execution results, and end-to-end pipeline
demonstration. Chapter~6 concludes the work with a summary of contributions, an
assessment of the research objectives, a candid statement of limitations, and directions
for future work.
